# 1. Introduction & Overview
> Purpose, audience, system description, objectives and requirements (REQ-IDs), scope and non-goals, background, document overview.

# 2. System Architecture
> Diagram, components table, style and patterns, key decisions (DEC-IDs) with alternatives, cross-cutting concerns, tech stack.

# 3. Data Design
> ERD, storage choices, schema, data flow, validation and integrity, access patterns, retention/backup/privacy/migration.

# 4. Interface Design
> Interface inventory, API conventions, endpoint specs with examples, events, error model, security/auth, third-party integrations.

# 5. Component Design
> Per component: purpose, responsibilities, interface, logic/pseudocode, data structures, dependencies, failure modes, tests.

# 6. User Interface Design
> Users and tasks, workflows, screen inventory and specs (all states), navigation/responsive, accessibility, design system.

# 7. Assumptions & Dependencies
> Assumptions (ASM-IDs) with validation and impact, dependencies, constraints, regulatory/compliance, risk summary.

# 8. Glossary
> Terms, acronyms, domain jargon with section links.
