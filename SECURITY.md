# Security Policy

## Scope
This repository contains Markdown instructions (skills) and small helper
scripts. It does not run a service or handle user data. Relevant security
concerns include:
- Skill instructions that could cause Claude to take unsafe or deceptive actions.
- Helper scripts (`scripts/`) with unsafe behavior.
- Leaked secrets or credentials committed to the repository.

## Reporting a vulnerability
Please **do not** open a public issue for security concerns. Email
**h.a.ghanizadeh@gmail.com** or use GitHub's
"Report a vulnerability" feature under the repository's Security tab. Include a
description, the affected file, and steps to reproduce. You can expect an
acknowledgement within a few business days.

## Supported versions
Only the latest released version receives fixes.
